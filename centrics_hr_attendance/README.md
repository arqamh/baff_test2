==========================
HR Attendance Extend
==========================

This Odoo module extends the functionality of the default HR Attendance module by introducing manual attendance logging and automation for system record creation.

Key Features
============

- 🔧 Configurable manual attendance entry
- 📋 Manual attendance log management
- ⚙️ Automated creation of HR attendance records from manual logs using scheduled jobs (cron)

Usage
=====

1. Define attendance import configurations in the system.
2. HR officers can record attendance manually using the provided forms.
3. A scheduled cron job processes manual logs and creates official HR attendance entries accordingly.

Installation
============

1. Place this module inside your custom addons directory.
2. Update the app list and install the module from the Apps menu.

Dependencies
============

- `base`
- `hr_attendance`
